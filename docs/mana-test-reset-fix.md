# 魔力恢复与单局苹果成长

2026-10-20，显示版本 **0.1.2**，构建 **0.7.0**，Minecraft **26.3 / Java 26**。

四端魔力苹果增加的上限现在**只在本局有效**。同一局断线重连保留成长；结束或重开对局、重新载入探索记录后，上限恢复 **100**。当前魔力超过 100 时截为 100，低于 100 的已消耗魔力保留。旧探索文件中的成长也会清除，学习、选槽和剩余冷却保留。

开发魔法测试是本局内的临时会话：结束测试仍恢复本局测试前的状态，例如 **63/120 → 测试 300/300 → 63/120**；本局结束或重载后变为 **63/100**。不会因为结束开发测试而提前清除本局苹果成长。

Fabric、Forge、NeoForge 还补上首次测试前保存正常探索记录、登录时先结束残留测试再同步 HUD，并清理带标记的临时总魔典。普通总魔典和法术书保留。帮助中已有的 `/tlb magic teststop` 也已补齐，原 `/tlb magic test stop` 继续可用。Paper 原本已有该指令，本批更新其探索成长保存与旧记录迁移。

## 安装与操作

单人存档／本地开房：替换自己客户端对应加载器的模组 JAR，重启游戏，本地服务端逻辑也包含其中。独立服务器：替换对应模组或 Paper 插件 JAR 后重启。显示版本仍为 0.1.2；安装入口见[安装说明](install-0.7.0.md)。

测试中执行 `/tlb magic teststop`，或点击目录中的“结束测试并恢复原记录”。关闭目录、按 Esc 或收起总魔典只收起界面，以便正常施法，不会结束测试。中英文魔力苹果说明已注明仅本局有效。

正常保存退出先恢复测试记录再保存；异常中断前也已保存正常记录，磁盘不会再携带本局苹果成长。这个规则清理上限成长，不删除探索学习记录。

## 复现与结果

最初真实 Fabric 隔离回归发现：最新正常状态为 63/120，旧盘为 83/120，原实现进入测试前没有更新磁盘；新连接遇到残留测试时，首包仍为 300/300。另一个独立问题是说明中的 `/tlb magic teststop` 没有注册，命令被拒绝后测试仍继续回满。

新增单局要求后的回归先确认旧实现仍保存 120 上限而失败。最终版本实测：

```text
MANA_RESTART_CHECKPOINT correct=true expected=63/100 stored=63/100
MANA_RESTART_FRESH_CONTROLLER mana=63 max=100
MANA_RESTART_JOIN testing=false mana=63 max=120
MANA_ROUND_ONLY_GROWTH_PASS reconnectCap=120 endedCap=100 nextCap=100 migratedCap=100
TLB_MAGIC_TESTSTOP_PROBE PASS assertions=149 hudPackets=62
```

其中 JOIN 是同一运行会话内恢复测试前状态，所以仍为本局 120；新控制器读盘、局后与下局均为 100。正常保存退出本来已有恢复路径，本次补充了异常中断与残留连接的边界，并调整了长期保存规则。

## 验证范围

- `python scripts/test-magic-teststop.py`：真实 Fabric 命令树、菜单按钮、控制器、持久化文件、物品栏和 HUD 网络包，**149 项断言**。覆盖付费魔力保存、120／300 本局成长、重载回到 100、同局重连、局后与下局重置、旧记录迁移、权限、重复退出、临时书清理及正常物品保留。日志为 `.tools/magic-teststop-regression/round-cap-{before,after}.log`。
- 真实 Paper 针对回归 **31 项断言**：旧 170/200 → 100/100、63/120 → 63/100，迁移写盘；非法旧上限 105 仍拒绝。本局重连／结束开发测试保持 120，结束／重开对局恢复 100，学习、选槽与冷却保留。日志为 `.tools/paper-mana-round-probe/actual-paper.log`。探针 JAR 由原发行 JAR 覆盖本轮生产类形成，最终发行包会核对被测类字节。
- 公共规则 **1,276,612 项断言**通过，包含成长归一化、付费魔力与冷却保留；日志 `.tools/mana-round-cap-compile.log`。
- 客户端原生产 `receive → tick → hudModel` 三端共 **36 项断言**：300 → 73/100、空学习列表、同一会话 140 上限、断开和直接切换身份。NeoForge 使用原版 26.3 客户端 API 夹具，生产类按自己的平台库编译。日志 `.tools/mana-client-reset-probe/probe-{fabric,forge,neoforge}.log`。
- 三模组控制器按平台命名归一化后一致，Java 26 编译通过；Forge、NeoForge 另通过本轮最终类的隔离服务端启动。所有通过的真实服务端回归退出码与项目错误扫描均为 0。

历史诊断记录 `.tools/fabric-mana-lifecycle-{before,after}.log` 验证了新同 UUID 玩家首包由 300/300 恢复为原值；其中成长长期保存的旧预期不代表本批最终规则，以本页和 round-cap 回归为准。

以上包含真实生命周期入口与新控制器读盘，不代表已完成图形客户端中关闭整个游戏、重新启动再进入存档的人工试玩。仅操作 `.tools` 隔离服务器，测试后临时探针与夹具数据恢复，不改动用户存档。
