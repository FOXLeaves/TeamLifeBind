# RG 肉鸽远征

2026-11-02。显示版本 **0.1.2**，内部构建 **0.7.0**，Minecraft **26.3 / Java 26**。Fabric、Forge、NeoForge 与 Paper 都提供 RG；默认模式继续是 SUR。

## 开始一局

管理员在大厅选择：

```text
/tlb mode rg
/tlb pve normal
/tlb start
```

也可在 `/tlb campaign` 菜单选择 RG、挑战难度与团队重生额度。`/tlb pve easy|normal|hard` 同时用于 PVE 和 RG，只影响怪物强度。配置的游玩模式保存为 `RG`，每局的路线和遗物使用全新随机种子。

RG 支持单人及多人合作。既有生命绑定、图腾救援、魔法、队伍床和协作道具继续使用；随机魔典子赛制也可搭配 RG。新玩家不能中途加入正在运行的挑战，原参与者按原有身份与重生规则重连。

## 十层远征

每层开始前提供三条路线。路线包含敌群主题、挑战词缀及一件团队遗物；首次选择也会获得遗物。每层在本局战场展开，完成十层即通关，第 5、10 层有首领与实时血条。

- 同战场内有资格行动的在线参赛者每人一票，点击路线或用 `/tlb rg 1`、`2`、`3` 投票；锁定前再次选择会替换自己的票。单人直接确定，多人过半票或全员投完立即确定。
- 首票开始 **20 秒**倒计时，到期按最高票决定；平票采用编号较小的路线。没人投票时不会倒计时，重复投票和改票不延长时间。菜单与 HUD 显示实时票数、自己的选择和剩余时间。
- 离线、旁观、待重生或离开战场的玩家移出票池，已有票也撤销；这可能让剩余票达到多数。全部有效票撤销后等待新的首票。原参与者重连且恢复行动资格后自动收到待选路线，可以重新投票。
- 菜单可随时关闭，用 `/tlb rg` 重新打开；这些操作不要求管理员权限。路线锁定时才授予一次全队遗物，投票过程不提前发奖励。
- 未选路时不会自动开始下一层。选路后至少准备 10 秒，关间原有的至少 20 秒休整仍保留。
- 每组路线只能领取一次，旧窗口和重复点击不会重复授予遗物；满级遗物不再出现在候选中。
- 遗物直接记录在本局角色效果中，不占背包。菜单下方的书可打开完整远征面板。

六种敌群主题是疫潮荒原、白骨猎场、掠夺营地、盘丝巢穴、寒霜边境和失落遗迹。不同主题组合僵尸、尸壳、蜘蛛、骷髅、流浪者与卫道士。每组候选的三个主题、词缀和遗物各不重复。

| 词缀 | 实际效果 |
| --- | --- |
| 蜂群 | 普通敌人数约增加 25%，全部敌人生命减少 20% |
| 精英 | 普通敌人数约减少 25%，至少 3 名；全部敌人生命增加 50%、伤害增加 10% |
| 迅捷 | 全部敌人移动速度增加 18% |

数量取整且每层总敌人数最多 48。生命与伤害叠加关卡、开局人数及所选难度；骷髅和流浪者的箭矢同样使用伤害倍率。只统计本局登记的敌人，缺失补怪和自然生物不会提供额外清关进度。

## 随时查看远征面板

选路时点击菜单下方的书，其他阶段直接使用 `/tlb rg`。面板显示当前层、准备时间／剩余敌人、难度、已完成层数、击破数、用时、远征编号和当前路线；八种遗物各自显示当前等级、上限与每级效果，尚未获得的也会列出。

面板按秒刷新，查看时对局继续进行。选路阶段可从底部箭头返回投票，战斗阶段用底部按钮关闭。原参与者在旁观或待重生期间仍能查看面板，但不能投票；中途加入的非参赛者不能操作。所有图标只作展示，不会进入背包。结束或重开会关闭旧面板，旧窗口不能操作新一局。

## 八种团队遗物

| 遗物 | 每级效果 | 等级上限 |
| --- | --- | --- |
| 锋刃纹章 | 近战攻击力 +12%；魔法和枪械不变 | 3 |
| 铁壁纹章 | 护甲 +2 | 3 |
| 风行羽 | 移动速度 +6% | 3 |
| 连击齿轮 | 近战攻击速度 +10% | 3 |
| 不动之锚 | 击退抗性 +0.1 | 3 |
| 回响泉眼 | 每秒额外恢复 2 魔力 | 3 |
| 行囊祝福 | 每次清关额外获得 4 食物和 1 魔力药水 | 2 |
| 秘卷残页 | 清关魔法书奖励提高 1 阶 | 2 |

同一遗物的等级先相加，再应用一个对应加成。秘卷残页在终层之前最多提升到七阶，八阶书属于最终清关奖励；它不改变世界自然箱和空投的爆率。回响泉眼恢复当前魔力，魔力上限苹果依旧仅本局生效。学习上限仍是三种魔法。

## 失败与清理

RG 默认使用 **3 次团队重生额度**：前三次普通团灭分别消耗一次并允许重生，额度为零后再次团灭结束本局。管理员可在赛制菜单调整额度，开局后固定。该额度独立于屠龙／随机魔典子赛制，成功的图腾救援仍按原规则处理。

通关后保留 20 秒查看奖励，再返回大厅。结算显示本局关数、实际击破数、用时、远征编号和遗物强化次数；用时包含选路和关间休整，不包含最终奖励停留。额度耗尽结束时显示挑战失败和本局统计。

遗物、路线和挑战奖励仅本局有效；正常结束、失败、手动停局或重新开局都会清理。RG 不向 SUR 生存背包写入这些奖励，也不保存跨局遗物。模组属性加成使用不写入玩家存档的临时修饰符；Paper 在退出、停止、插件启动和玩家登录时清理自己拥有的遗物属性键，处理异常重启后的残留，并保留其他来源的属性加成。

## 验证

RG 公共回归通过 **146,632 项**断言，公共层合计 **1,430,685 项**。覆盖随机种子复现、路线多样性、三选一互斥、重复和跨局点击、满级候选剔除、人数／敌人数上限、十层状态机、奖励阶级以及各子赛制下的重生额度；新增单人、多数、平票、改票、弃权超时、撤票重连和全部 256 种四人投票／弃权组合。记录为 `.tools/rg-coop-compile.log`。

Fabric **1,073 项**、Paper **353 项**完整模式回归通过，包含原 SUR／PVE／PVP 流程。两端都使用真实隔离服务端、实际菜单、玩家属性及怪物完成 RG 十层，固定测试路线各击杀 **87 名**挑战敌人，覆盖全部八种遗物、回魔幂等、实际魔法书和食物奖励、首领血条、重生额度耗尽和结束清理。新增四名测试玩家的实际投票、改票、掉线和原身份重连、超时、战斗面板、旁观只读与图标防取出；Paper 另验证菜单延迟回调不会误关新面板、真实登录会清理模拟异常重启留下的属性。记录为 `.tools/play-modes-regression/rg-coop.log`、`.tools/modes-paper-probe/actual-paper.log` 及各自的 `tested-classes.json`；两套测试世界和配置均已还原。

Forge、NeoForge 通过四端编译、隔离服务端启动及 `mode rg` 命令检查，这两端未独立重跑完整十层。最终发行文件与已测类文件的哈希对应关系记录在 `.tools/rg-coop-release-2026-11-02-evidence.json`。图形客户端多人试玩未覆盖。
