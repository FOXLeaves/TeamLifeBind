# 生存、闯关、肉鸽与团队对抗

更新于 2026-11-02，游戏显示版本 **0.1.2**，内部构建 **0.7.0**，Minecraft **26.3 / Java 26**。

独立游玩模式包括默认的 **SUR 合作生存**、**PVE 合作闯关**、**RG 肉鸽远征**和保留原比赛的 **PVP 团队对抗**。原来的屠龙、限命、随机魔典继续作为子赛制存在；RG 额外启用本局团队重生额度，详见[肉鸽规则](roguelike.md)。

| 模式 | 人数与队伍 | 世界和目标 |
| --- | --- | --- |
| `sur` | 首位玩家登录自动开始，参加者为同一合作队，中途可加入 | 持久生存世界，持续探索、建设与成长；击杀末影龙不结束生存 |
| `pve` | 一人或多人合作；新玩家不能中途加入正在进行的挑战 | 十关敌潮，第 5、10 关为首领关，完成第十关通关 |
| `rg` | 一人或多人合作；队伍共享路线、遗物和重生额度 | 十层随机遭遇，每层三选一并支持团队投票、远征面板，局内成长；见[RG 肉鸽玩法](roguelike.md) |
| `pvp` | 至少两人，按原设置分配 2–32 队 | 原有比赛场地与胜负规则，保留屠龙、限命和随机魔典玩法 |

## 开始和切换

默认 SUR 会在首位玩家登录后直接开启合作生存。模组端沿用原版存档的玩家位置和背包。Paper 进入持久的 `tlb_survival` 世界。旧大厅存档从生存记录恢复，缺少记录时使用生存出生点。

想换玩法时，管理员可先执行 `/tlb stop`，再用 `/tlb mode sur|pve|rg|pvp` 或 `/tlb campaign` 选择，最后用 `/tlb start` 开始。暂停 SUR 后留在生存世界，重启服务器后再次自动开启。`/tlb status` 和 `/tlb rules` 会显示当前模式。

子赛制命令继续可用：`/tlb mode DRAGON_HUNT`、`/tlb mode LIMITED_LIVES`、`/tlb mode RANDOM_GRIMOIRE`。这些命令修改子赛制；游玩模式由 `sur/pve/rg/pvp` 独立控制。最后一击／贡献、重生额度、据点与收圈等配置也保留，开局时捕获本局设置。运行中不能直接改变模式，应先结束当前会话。

Paper 配置：

```yaml
gameplay:
  play-mode: SUR
  pve-difficulty: NORMAL
  match-mode: DRAGON_HUNT
  team-lives: 3
  dragon-victory: LAST_HIT
  control-point-enabled: false
  border-enabled: false
```

模组的 `config/teamlifebind/settings.properties` 对应 `play-mode=SUR`，其余子赛制键保持原名。缺少 `play-mode` 的旧配置使用新默认 SUR；已有明确的 `PVP` 选择会保存。需要继续原版比赛时，选择 `/tlb mode pvp`。

## SUR 持久合作生存

生存使用持久世界和独立的背包、经验与位置记录。Fabric、Forge、NeoForge 使用本存档的原版主世界／下界／末地。Paper 使用固定的 `tlb_survival`、`tlb_survival_nether`、`tlb_survival_the_end` 世界家族。在生存世界重连时沿用当前的玩家数据，从大厅或其他模式返回时恢复生存记录。

运行中的 SUR 可以接收新参与者，加入原合作队，不会重置已有队员的任务和团队冷却。生命绑定、血量及其他队内共享、队伍床、图腾、药水、300 种魔法、自然箱、建筑物资和空投继续使用原机制。合作模式阻止玩家互相造成战斗伤害；杀龙不产生竞争胜者。普通死亡仍按已配置的共享死亡与重生规则处理，永久淘汰不会被新玩家加入绕过。

生存物品和世界进度与临时对抗／闯关分开。死亡后会使旧背包快照失效，避免再次进入时重放死亡前物品；离线队员的生命连坐会延续到下次登录，停止会话或重启不会取消已发生的死亡结算，并遵守当前世界的 `keepInventory` 规则。开发测试产生的临时魔典也不作为正式奖励保存。生存记录所在位置：

- 模组：`<存档>/data/teamlifebind-survival/<UUID>.dat`。
- Paper：`plugins/TeamLifeBind/survival-playerdata/<UUID>.yml`。

魔法学习沿用探索记录。魔力苹果仍遵守仅本次会话有效的规则，停止／重开或重新载入后上限恢复 100，不能借持久世界带入永久魔力成长。

## PVE 十关合作挑战

管理员可用 `/tlb pve easy`、`/tlb pve normal`、`/tlb pve hard` 选择闯关难度，也可在 `/tlb campaign` 的钻石剑按钮上切换。先用 `/tlb mode pve` 选择闯关模式，再选择难度并 `/tlb start`。难度会保存；缺少新配置的旧存档使用标准档，开局后本局设置固定，运行中不能更改。

| 难度 | 相对原关卡的怪物生命 | 相对原关卡的伤害 |
| --- | --- | --- |
| `easy` 休闲 | 75% | 75% |
| `normal` 标准 | 100% | 100% |
| `hard` 困难 | 135% | 125% |

这些倍率作用于普通敌人与首领，叠加关卡和人数缩放。骷髅与流浪者的箭矢已补上独立的伤害缩放，因为原版箭矢不读取近战攻击属性；自然生物与玩家箭矢不受此设置影响。它们只调整 PVE 怪物强度；原版世界难度、玩家血量预设、敌人数上限、补给与魔法书奖励概率各自按原规则执行。Paper 配置是 `gameplay.pve-difficulty`，三模组配置是 `pve-difficulty`。

挑战开始后准备 **10 秒**再生成第一关；清理每关敌人后休整 **20 秒**。第 5、10 关包含强化首领，其余关卡逐渐组合僵尸、骷髅、蜘蛛、尸壳、流浪者和卫道士。人数只在开局捕获，按最多 16 人缩放，每关最多 48 名挑战敌人；更多参与者不会继续无限加怪。

每关补充了与敌人组成对应的名称，准备和休整时预告下一关及倒计时。第 5 关「破城巨兽」和第 10 关「裂隙统领」显示独立首领血条，包含本局难度与实际生命值；仅同维度的本局参赛者收到血条。首领死亡、离线、离开维度、停止或重开都会清理对应显示，返回战场后显示当前进度。

怪物生命和伤害随关卡及人数增强，主动寻找参与者。侧栏显示当前关卡、剩余敌数和下一关倒计时。每个实际完成的关卡只结算一次补给；完成第十关后保留 **20 秒**通关停留，可查看和使用最终奖励，随后按原比赛结束流程回到大厅。闯关奖励属于本局，不带入 SUR 的生存背包。不以击杀末影龙或“只剩一个合作队”提前获胜。新玩家中途进入为旁观，原参与者重连仍按本局身份与重生状态处理。

只统计本次挑战登记的怪物，杀死自然生成的生物不会推进关卡。怪物卸载、消失或越界不等于击杀；缺失槽位需要重新生成，不能通过卸载怪物跳关。生成未完成会结束挑战，不发放空波奖励。清理本局时只移除挑战生成的怪物，保留其他世界生物。

通关结算显示本局难度、完成关数、团队击破数和用时，只发送一次。击破数只统计本局登记敌人的真实死亡，重复事件、自然怪与缺失补怪不计入。用时按服务器游戏刻计算，包含准备和关间休整，截止到最后一名挑战敌人死亡，不计最后 20 秒奖励停留。

既有生命绑定、图腾救援、魔法、重生额度等规则仍参与挑战，临时全员死亡但存在合法待重生时不会仅因人数暂时为零而结算成功。全体永久淘汰或挑战生成失败则本次未通关。和平难度不能生成敌潮，需要使用可生成敌对生物的难度。

## 既有机制与平台区别

PVP 的队伍分配、竞技胜负、限命、贡献屠龙、随机魔典、队伍床、图腾、魔法、协作道具、据点和边界开关保留。三个模组继续保留空投限定枪械、无限备弹与可重绑操作；Paper 继续没有枪械。建筑只在符合原规则的新区块生成，取走物资或重新开始生存不会补满已生成的容器。模组魔法继续使用内置着色器，Paper 使用原有表现。
