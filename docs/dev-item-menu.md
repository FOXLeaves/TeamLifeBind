# 开发者测试物品目录

管理员在游戏内执行 `/tlb dev`，可查看并领取基础测试物品，再通过魔法入口或 `/tlb dev magic` **选择一项魔法物品**。Fabric、Forge、NeoForge 提供 **19 类基础物品**，加上 300 本法术书与五件魔法伴生物品，共 **324 个可领取条目**；Paper 已移除七把枪械，提供 **12 类基础物品、共 317 个可领取条目**。魔法分类四端一致，不会一次发入背包；信息卡、入口与装饰边框不计入领取物品。游戏显示版本保持 **0.1.2**，内部构建编号 **0.7.0**，运行环境为 **Minecraft 26.3 / Java 26**。

## 魔法分类

默认魔法入口先显示 **16 个分类：14 个普通学派、超位、伴生物品**。选择学派后显示它的 20 本普通书，超位分类显示 20 本，伴生分类显示总魔典、普通/高效魔力药水、魔力苹果和遗忘之书。点击具体物品进入详情，选择“领取一件”才会发放一件。每一项法术显示阶位、魔力、冷却与机制说明；完整 ID 与数值见[300 本目录](magic-catalogue.md)。

法术详情另外提供**测试槽 1 / 2 / 3**。点击可直接在临时测试记录中替换该槽法术，并给予临时 300 魔力上限、300 当前魔力和清空的冷却，不需要领取或学习大量书籍。最多三个槽；新增时按 1、2、3 顺序填充，已有槽可以反复替换。施法仍用主手总魔典与正常平台操作，主手已有总魔典可复用；需要新载体时只在空格加入一本带标识的临时魔典，背包满会拒绝创建，不覆盖原有物品。

点击“结束测试并恢复原记录”或执行 `/tlb magic teststop` 可结束会话，恢复原来学习、选槽、魔力、上限与按经过时间衰减的冷却，并清理生成的临时魔典。退出服务器、撤销管理权限和开局也会恢复。临时知识与魔力不会进入正式探索存档。需要测试正常学习、药水或苹果时先结束临时会话；模组会拒绝测试期间消耗这些道具，Paper 会先结束临时会话再正常处理。

2026-10-20 三模组增加首次测试前保存与登录恢复，清理带标记的临时总魔典，并补齐 `/tlb magic teststop`；旧入口 `/tlb magic test stop` 仍可用。**关闭目录或按 Esc 只收起界面，不结束测试**。结束开发测试会恢复本局测试前的数值，例如 `63/120`；四端苹果成长则仅本局有效，同局重连保留，结束／重开对局或重载探索记录后上限恢复 100，普通总魔典与探索学习记录保留。见[修复记录](mana-test-reset-fix.md)。

快捷命令 `/tlb magic test <法术ID> [1–3]` 与详情测试槽相同，省略槽位时使用当前选择。旧的 `/tlb dev magic <1–7>` 平铺页保留，每页 45 项，点击物品同样进入详情，翻页和关闭不发放道具。

可直接执行 `/tlb magic give <id>` 领取指定的一件法术书或伴生物品。领取的学习书遵循正式学习规则，管理员不会因领取而自动学会或突破三槽限制；这与临时测试槽不同。预览图标带专用标记，不能被学习；领取时重新创建有效物品，既有预览不会被复制成奖励。魔法单件领取在背包没有空格时提示并拒绝，不产生地面掉落。魔法学习、三槽操作、掉落与随机开局说明见[魔法玩法](magic-system.md)。

## 领取规则

Paper 需要 `teamlifebind.admin` 权限，模组需要原版游戏管理权限；普通玩家不能打开目录。每次点击都会重新检查权限，已打开菜单后被撤销权限也不能继续领取。信息卡与边框不发放物品，目录中的源图标保持原位，便于重复测试。基础测试物品（模组 19 类、Paper 12 类）在背包不足时保留脚边掉落行为；**魔法选择器及 `/tlb magic give` 只在有空格时领取**。

三模组的枪械图标仅用于展示名称、外观、弹匣和测试用途，不持有可开火的有效武器序号，也不登记服务端战斗状态。反复打开或刷新目录不会耗用武器状态额度。管理员点击枪械时，调用正式武器工厂创建新 UUID 和满弹状态，不复制预览图标。连续领取同一枪型也会得到互相独立的武器，其弹匣余量分别保存。

模组武器工厂达到当前会话的状态上限时，目录仍可浏览，领取枪械会提示上限，不生成无效武器。具体弹匣与装填规则见[枪械玩法](airdrop-weapons.md)：Vector45 为 20 发、SPAS-12 为 5 发，Minigun 无限供弹。

三模组的正常对局仍只通过空投获得枪械，每个成功开启的空投箱随机生成一把。枪械没有合成配方，所有枪械无限备弹。没有活动比赛时，存活且非观察者的玩家可使用有效测试枪开火、瞄准和换弹，无需先分队或开局；进入投票或倒计时后暂停枪械使用，正式比赛仅存活参赛者可用。管理员领取权限与这些使用条件分别检查。Paper 空投保留魔法与其他补给，不再生成枪械。

模组专用大厅维度的玩家 PvP 保护继续生效；大厅测试可用生物作为命中目标。弹匣和热量 HUD 在无活动比赛时同样显示。投票与倒计时阶段所有玩家均暂停枪械；正式比赛中的未参赛大厅玩家也不能使用测试枪绕过参赛资格限制。

## 安装后手工检查

1. 使用对应平台的新 JAR 重启实例，管理员执行 `/tlb dev`，核对八件基础道具与四件辅助工具；模组另有第五行七枪，Paper 不显示枪械领取项。检查名称、外观与说明。
2. 领取共鸣哨、应急绷带，再切换语言重新打开目录并领取，确认说明正确。
3. 在模组端连续领取同一种枪两把，没有活动比赛时可在大厅测试。消耗其中一把的弹药，再切换另一把，确认第二把仍为满弹。默认左键开火、右键瞄准、R 换弹，单独右键不能开火；检查重绑后的按键也分别执行对应操作。Paper 检查普通物品的 F 副手交换正常，总魔典仍用 F 切槽。
4. 用普通玩家执行 `/tlb dev`，确认拒绝打开；管理员打开菜单后撤销权限，再点击物品，确认不继续领取。
5. 模组在活动比赛中确认观察者、淘汰者和未参赛者不能使用枪械；每个成功开启的空投箱只有一把随机枪，合成台没有枪械配方。Paper 确认空投和开发目录均不生成枪械，旧版带枪械标记的物品迁移为普通铁马铠。四端背包满时基础物品按原规则掉落，信息卡和边框不能领取。
6. 执行 `/tlb dev magic`，依次点击学派、法术和详情；确认浏览不占背包，只有“领取一件”发放一件。填满背包再领取魔法道具，应提示拒绝且不在脚边生成物品。
7. 记录自身已学法术与魔力，用测试槽切换不同法术，包括超位；确认最多三种，只需要一册总魔典。结束测试后核对原学习、魔力及冷却恢复；分别核对退出、撤权、开局的自动恢复。

以上为安装后手工检查步骤，未声明已通过真人客户端试玩。
