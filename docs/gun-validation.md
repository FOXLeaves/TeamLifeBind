随后按大厅测试反馈，将三模组的枪械使用条件与 Paper 分开：模组没有活动比赛时允许存活、非观察者玩家使用有效序号枪械，无需分队；进入投票或倒计时后暂停枪械使用，正式比赛仅存活参赛者可用。Paper 的比赛内使用条件与右键开火适配保持。原生客户端开火取攻击键、ADS 取使用键，默认左键 / 右键，换弹为可重绑的独立 R 键。本轮增加独立 Fabric 大厅夹具并扩展 Forge 原生测试；服务器夹具仍不能替代真人客户端操作验收。

实际 Paper API 没有 Spigot 编译接口中的 `ItemMeta.getConsumable()`。生产代码因此用共同的 `ItemFactory.createItemStack` 和固定原生组件语法创建物品，再设置模型与 PDC。使用状态另以玩家及枪械序号授权，取消后必须重新右键。真实 `CraftLivingEntity` 字节码确认 `getNoDamageTicks()` 对应 `LivingEntity.damageCooldownTime`，`getLastDamage()` 对应 `lastHurt`。

另以真实末影龙和原生 `ServerPlayer` 的真实 `CraftPlayer` 包装测试龙部位攻击；没有登记在线玩家或接入客户端。确认八个部位中仅头部判为爆头，同样 20 点攻击实际扣除头部 20 点生命、身体 6 点生命，每击只有一个普通伤害事件，直接及致因玩家均正确。取消事件和原生临时无敌仍能阻止伤害。所有新建龙和监听器均在 `finally` 清除。

Paper 的 `EnderDragonPart.damage` 会转发父实体，并由父实体选择身体部位。`ServerGunDamageCompat` 使用 Bukkit 的普通玩家攻击来源，将伤害交给实际命中的原生部位，从而保留头身区别和已有伤害事件。枪械作为马铠载体的装备路径也被禁止：右键和发射器马铠装备事件均拒绝，普通马铠及发射器正常抛物保持原行为。

新增六组聚合测试调用生产 `add` 与 `Impact.amount` 后，将结果送入上述真实原生部位伤害流程：头/身与颈/身的两个命中顺序均扣除 13.5 点生命，身体/身体扣 6，头/头扣 20，每组一个实际 Bukkit 伤害事件。没有让未登记在线的真实射手绕过 `applyDamage` 的对局资格检查；完整适配器资格仍由严格输入代理覆盖。

换弹音效在开始和完成时各播放一次；重复 F、满匣请求、换枪和取消不误播完成声。额外将生产公共状态机的同 tick 装满并立即开火结果送入生产 `reloadSound`，确认仍播放一次完成声，随后快照不重复。换弹请求绑定实际武器序号，旧枪意图不能转给新枪，新枪在替换后、下一个 tick 前请求换弹也不会丢失。

原生消耗组件使用 `minecraft:intentionally_empty` 音效，持续按住时不会产生吃东西声。复跑旧 Paper 回归通过：赛制 **95** 项、协作道具 **103** 项、游戏界面与延迟菜单 **168** 项。记录为 `.tools/paper-guns-campaign-utility-0.7.0.log` 与 `.tools/paper-guns-gameplay-0.7.0.log`。
