# 魔法目录：280 种普通魔法与 20 种超位魔法

本表由 `scripts/ExportMagicCatalogue.java` 从 `SpellCatalogue` 导出。操作、掉落和伴生物品见[魔法玩法说明](magic-system.md)。每位玩家最多学习三种；同阶内的书等概率抽取。伤害列是运行时计算使用的基础伤害点数（2 点 = 1 颗心），不等于整次法术必然造成的总伤害：投射方式、命中次数、学派互动、护甲、抗性、遮挡与事件取消都会影响结果。

300 项各有显式的独立触发配置，包括首次命中、重复命中、持续脉冲与结束后动作；条件包含残血、悬空、着地、潮湿、燃烧和距离。即便忽略 ID、名称、学派、颜色及数值，300 项的触发/动作结构与四阶段动态图样仍各不相同。碰撞、生命周期与 24 种动作组件由服务器执行器复用。超位还有专属阶段时长及开场/收尾动作。

## 图样与动作

每个法术的吟唱、飞行、命中和收尾分别使用几何图样，与旋转、反转、脉动、上升、折叠、公转或内收运动相组合。采样点硬上限 64；高阶层次仍受服务器总粒子预算约束。图样不是仅靠改变粒子颜色或数字种子产生差异。

动作：点燃、浸湿熄火、凝霜、减速、缠根、虚弱、遮蔽视野、显形、悬浮、击退、牵引、挑空、击落、中毒、流血凋零、打断吟唱、消耗目标魔力、回收魔力、回复生命、吸收护盾、截断惯性、净化负面效果、延迟追击、局部爆发。
