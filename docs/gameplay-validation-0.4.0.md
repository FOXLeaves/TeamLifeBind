# 0.4.0 新玩法验证记录

验证日期：2026-10-12（Asia/Hong_Kong）。目标 Minecraft 26.3，Java 25、Gradle 9.8.1；本轮更新共鸣哨、应急绷带、动态补给、开箱争夺与首次终局预告。确定规则见 [玩法说明](gameplay-update-0.4.0.md)，平台版本与官方依据见 [升级研究](upgrade-research.md)。

0.4.0 玩法实现的四端构建、隔离启动、自动检查与发行包核验通过。本次追加的原创 32px 材质已完成资源检查、四端重建与新发行包核验；下述玩法断言和服务端启动来自材质加入前的 0.4.0 验证。真实客户端模型、真实玩家伤害链和多人完整对局仍未实测；以下区分共享规则、代理玩家检查和原生方块/事件检查。

## 构建与资源

Windows PowerShell 使用 Java 25 和独立 Gradle 缓存，执行四端 build、bundleRelease、scripts/verify-resources.py 与 git diff --check。开发运行目录为 .tools/smoke-26.3/，未使用用户原有 run/ 世界。

- 共享规则通过 **4,821 条断言**，比 0.3.0 增加 **417 条**。覆盖补给开关/动态与固定数量、提前 60 秒预告、标记与冷却边界、读条互斥、取消不消耗冷却、同箱单次完成、清理后旧回调失效和 8 线程并发竞争。
- 本次资源校验通过：**29 份共享文件、85 个 JSON/pack 元数据、12 个模组语言键、344 个公共语言键**。两份原创 32px RGBA PNG 的透明背景、完整性、模型映射及三端字节一致性通过检查；未观察真实客户端渲染。
- 四端 JAR、插件资源包、README、LICENSE、CHANGELOG 和 11 份文档组成 **19 文件**的新发行 ZIP，重建与归档核验通过。确认生产 PNG、元数据、加载器版本、common Java 21/平台 Java 25 字节码、必需 Mixin、模型/配方及资源包格式 97.1；包括[材质规范](item-textures-0.4.0.md)的归档文档字节与当前源码一致。
- 发行包 SHA-256 另存同目录的 .zip.sha256 文件，避免把归档自身校验值写入归档内文档。插件资源包 SHA-1 同样提供独立校验文件。
- GitHub Actions 未远程执行；本机结果不记为远程 CI 通过。

## Paper 集成代理检查

旧玩法探针保留全部 **168 条断言**，仅适配 0.4.0 版本门槛。真实 Bukkit inventory/PDC、命令分发和主线程产品代码覆盖规则卡、权限、预设循环与持久化、延迟菜单重开、本局快照、冷却清理，以及 2/10/20 最大 HP 的强化救援参数。玩家为严格内存代理，未知调用会失败；没有真实 NMS 属性钳制或复活流程。

新 Utility 探针通过 **103 条断言**：

- 真实物品 PDC、模型入口、堆叠上限和两份无序配方；代理玩家的绷带团队互斥、冷却、取消与手槽变化不消耗物品，开始/完成时满血不消耗或加冷却。
- 调用实际治疗与普通同步函数，确认团队只获得一次治疗，不按队员数重复累加；同步关闭时个人治疗受最大 HP 限制。
- 发布实际 InventoryClick/Drag，确认无关槽位操作保留读条、触发手槽及数字键换槽打断；暂离队伍和普通复活倒计时仍计入动态数量，永久旁观者排除。
- 发布实际已取消/零伤害 EntityDamageByEntity 事件，确认攻击仍打断绷带及开箱，监听器保持原伤害值与取消状态，不消耗物品、冷却或补给奖励。
- 在真实隔离世界放置空 BARREL，检查原生锁/PDC、实际 BlockBreak 和漏斗事件保护、空主手启动、副手/非空主手拒绝、右键预测摆手不误取消；异队争夺完成只填一份战利品，竞争者及重复回调不能再次填充。
- 清理时取消读条、解除空桶原生锁及 PDC，不生成奖励；finally 恢复 Bukkit 查找、引擎、配置与控制器状态，删除临时方块并释放探针区块票。

该探针发布真实 Bukkit 事件，但玩家仍为代理，没有网络包、真实攻击或 NMS 伤害推进。治愈与库存结果不等同于客户端观感或真人完整对局验收。

## Forge 原生方块与事件检查

临时组件在真实 Forge 服务端通过 **77 条断言**。使用原生 BARREL、容器及 Mixin 注入，检查未解锁前的插入、漏斗、爆炸、活塞和方块替换保护；8 秒前不能完成，解锁后恢复普通行为；同箱重复/竞争完成只生成一份奖励。

修复 Forge 7 五处 Predicate 返回方向为 true=cancel，覆盖 AttackEntity、LivingAttack、LivingUseTotem、RightClickItem 和 Break 的允许/取消分支。实测同队/敌队攻击、环境攻击、末地普通/强化图腾、投票和大厅菜单。锁箱 BreakEvent 另设置 Result.DENY，检查 BUS.fire 的结果以及 ForgeHooks.onBlockBreakEvent 返回 -1 的真实拒绝链。

事件测试使用无网络连接的原生 ServerPlayer 并发布实际 EventBus 事件；没有用真实攻击推进 hurtServer 或完整救援流程。Fabric/NeoForge 完成编译、资源与启动检查，本轮没有为它们运行同等的原生玩家/容器探针，不能把 Forge 的 77 条结果直接视作另两端通过。
