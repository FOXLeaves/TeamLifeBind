# 0.1.2 玩法更新（构建 0.7.0）

本次将原计划的 0.4.1、0.5.0、0.6.0 与 0.7.0 合并为一次更新，游戏版本保持 Minecraft 26.3，当前构建与运行使用 Java 26。**游戏内及四端插件/模组元数据的显示版本固定为 0.1.2**；文件名中的 0.7.0 是内部构建编号。内容包括床与药水状态提示、断线处理、静默符、侦察火箭、可选限命赛、屠龙贡献结算、契约据点、阶段任务与终局收圈。当前环境检查见[Java 26 验证](java26-validation.md)，迁移前玩法检查见[原验证记录](gameplay-validation-0.7.0.md)；安装见[安装说明](install-0.7.0.md)。

经典默认继续使用 `DRAGON_HUNT`、`LAST_HIT`、`CLASSIC` 节奏与 `CLASSIC` 图腾。据点和收圈默认关闭；新道具可合成使用。赛制、屠龙归属及地图目标开关在开局保存本局快照，在大厅调整后才影响下一局。

## 状态说明与断线

- 队伍 HUD 补充床状态，区分有效、被毁和无床；可查看所在维度与方向。床被毁不直接宣告全队永久淘汰，仍按当前赛制和死亡维度处理。
- 生命诅咒药水保留原物品和效果：血量同步开启时显示“生命解联药水”，使本队暂时解除血量同步；同步关闭时显示“生命共振药水”，将对敌方的有效攻击伤害回响至其队友。HUD 补充实际剩余秒数，默认效果仍为 180 秒；喝奶清除己方整队药水状态及相应豁免，包括离线队员保存的状态。
- 最近 10 秒内受伤或参与攻击的玩家断线，获得 30 秒重连宽限；按服务端 tick 计时。在宽限内回来可恢复本局状态，超时通过正常团队连坐路径处理一次。
- 非战斗断线不立即惩罚整队。断线期间若队伍已经团灭或被淘汰，重连会应用应有的重生/观战状态；断线不能避开队友团灭。结束本局会清理宽限与待处理状态。
- 限命赛中整队连续离线满 30 秒直接弃赛，即使未处于战斗也适用；仍有在线队友时，单人安全离线不会触发此规则。被团灭的离线成员返回后补上 5 秒重生倒计时；淘汰成员返回后保持观战锁定。
- 重连补团灭时按本世界 `keepInventory` 处理库存：关闭时掉落携带物品并清空库存与经验；已死亡或已进入重生倒计时的玩家不重复掉落，离线不能用来保住本应丢失的装备。

## 静默符与侦察火箭

| 属性 | 静默符 | 侦察火箭 |
| --- | --- | --- |
| ID | `teamlifebind:silent_sigil` | `teamlifebind:scout_rocket` |
| 无序配方 | 1 紫水晶碎片 + 1 回响碎片 | 1 烟花火箭 + 1 红石 |
| 产出 | 1 个 | 1 个 |
| 使用 | 比赛中右键，成功后消耗 1 个 | 比赛中右键，成功后消耗 1 个 |
| 持续 | 20 秒 | 5 秒 |
| 团队冷却 | 90 秒 | 45 秒 |
| 作用 | 整队暂时避开追踪轮盘与侦察火箭定位 | 显示同维度发射点 48 格内敌队方向，同时向附近敌人暴露发射方向 |

静默不提供隐身或无敌，不能阻止肉眼观察。侦察向发射队提供敌队方向与距离提示，向范围内敌人提供朝向发射队的警告；不公开敌人精确坐标，不透视轮廓，也不跨维度定位。旁观者不计入目标。消耗与冷却只有在资格校验和激活成功后发生；同队多人同 tick 使用不能绕过团队冷却。动作栏优先显示治疗/开箱读条，其次侦察、共鸣哨标记、轮盘定位。

两件物品均有原创 **32 × 32 RGBA** 透明像素材质，三种模组内置相同 PNG，插件端使用更新后的 0.7.0 资源包。生成原稿、提示词与机械导出说明见[材质规范](item-textures-0.7.0.md)。原有共鸣哨、绷带和动态补给继续保留，规则见 [0.4.0 说明](gameplay-update-0.4.0.md)。

## 限命团队赛

`DRAGON_HUNT` 保留经典屠龙目标。可选 `LIMITED_LIVES` 为每队配置 **3 次重生额度**；一次团队连锁死亡只扣一次额度，不按成员数量扣除。

| 普通维度团队连锁死亡 | 重生额度变化 | 结果 |
| --- | --- | --- |
| 第 1 次 | 3 → 2 | 可以重生 |
| 第 2 次 | 2 → 1 | 可以重生 |
| 第 3 次 | 1 → 0 | 本次仍可以重生 |
| 第 4 次 | 保持 0 | 全队淘汰、旁观 |

已启用的禁复活维度仍立即淘汰，不由剩余额度绕过；限命淘汰独立于经典禁复活开关生效。限命赛最后仍具比赛资格的队伍获胜；同一服务端 tick 的所有淘汰处理完成后再结算，无存活队伍为平局。击杀末影龙不会提前结束限命赛。离线成员继承本队额度、团灭和淘汰状态，不能通过重连恢复额度。队伍床只改变合法重生位置，不增加重生额度。

## 可选屠龙贡献结算

`LAST_HIT` 保留最后一击。可选 `CONTRIBUTION` 在末影龙死亡时汇总该龙最近 **60 秒**的实际有效 HP 伤害，由仍具比赛资格、贡献最高的队伍获胜。以伤害减免后的有效 HP 伤害计分，弹射物计入实际发射者所属队伍，过量伤害不超过命中前龙的 HP。此设置只影响屠龙赛制。

最高贡献并列时先选仍具资格的最后一击队伍，仍并列按队伍编号确定；没有有效贡献时回退有资格的最后一击队伍。贡献按队伍而非在线成员保存，普通断线不会抹去贡献。每次龙死亡和每局结果均只结算一次。

## 契约据点与阶段任务

可选据点位于比赛主世界的安全地表中心，范围为水平 6 格、上下 4 格。只统计存活且有资格的非旁观队员，同队人数不会加快进度。

一支队伍独占据点累计 **45 秒**获得本周期奖励；多队同时在场或无人时暂停，改由另一队独占则重新计时。每 **5 分钟**刷新周期，每队每周期最多领一次，发给捕获队的一位成员 **2 个应急绷带 + 1 个侦察火箭**。同时告知当前已规划的补给坐标，尚未规划时显示暂无落点。奖励不复活成员、不提升永久生命上限。

阶段任务为 **占领据点、成功夺取补给、抵达末地**；每队每局每项首次完成时公告一次，不另叠加资源奖励。队伍 HUD 显示进度，原有补给成功回调和维度进入事件接入任务。关闭据点后不会出现占点奖励；补给关闭时不会制造额外补给来完成任务。

## 可选终局收圈

开启收圈后，第 **24 分钟**公开预告；第 **25 分钟**公告开始并在 **10 分钟**内线性缩至主世界与末地半径 **250 格**，第 35 分钟到达最终半径。主世界初始半径至少 **750 格**，若队伍初始出生点更远则扩大为最远距离加 32 格，避免开启时截断出生区域。地狱采用主世界中心坐标和半径的 **1/8**，最低初始半径 93.75 格、最终 31.25 格；末地使用主岛安全中心。HUD 显示当前半径。停止、重新开局或禁用插件恢复本次修改过的边界。

## 配置

| Paper `gameplay` 下的键 / 模组键 | 默认 | 可选 |
| --- | --- | --- |
| `match-mode` | `DRAGON_HUNT` | `LIMITED_LIVES` |
| `team-lives` | `3` | 每队重生额度，可设置 1–10 |
| `dragon-victory` | `LAST_HIT` | `CONTRIBUTION` |
| `control-point-enabled` | `false` | `true` |
| `border-enabled` | `false` | `true` |

Paper 例如 `gameplay.match-mode`；模组 `settings.properties` 直接使用 `match-mode`。每局保存上述规则快照；`team-lives` 只在限命赛扣除，默认屠龙模式继续普通维度可重生的既有规则。

管理员可从大厅新增赛制菜单配置，也可使用 `/tlb mode <DRAGON_HUNT|LIMITED_LIVES>`、`/tlb dragon <LAST_HIT|CONTRIBUTION>`、`/tlb objectives <on|off>`、`/tlb border <on|off>`。重生额度在菜单或配置文件设为 1–10；比赛准备、倒计时及运行时拒绝切换。

全部计时按服务端 tick 计算，20 TPS 时对应本文秒数；低 TPS 时真实时间会延长。收圈与 `CLASSIC` / `FAST` 的补给和要塞事件时间分开。默认关闭；只处理本局战斗世界，不能改变大厅或其他玩家世界的边界。启用后需在实际客户端确认出生点、队伍床、传送门与末地平台的关系。

## 验收范围

共享状态机覆盖生命额度、同 tick 结算、重连截止、贡献窗口、团队冷却、据点单次奖励、任务去重和收圈边界；平台适配还需检查真实事件、配置快照、物品消耗、HUD 与清理。

至少完成 4 人 2 队对抗，以及两局连续开局、战斗断线重连、禁复活维度、限命 4 次团灭、并列屠龙贡献和三个战斗维度的收圈测试。自动检查结果与真人试玩分别记录，不把历史 0.4.0 的验证记为 0.7.0 通过。
